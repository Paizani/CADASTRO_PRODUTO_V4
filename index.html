💡 Conceito Bootstrap

Bootstrap é uma biblioteca de código aberto que facilita a criação de interfaces modernas e responsivas.

Ela oferece componentes prontos, como botões, formulários, tabelas, alertas e janelas modais.

Neste projeto, poderíamos utilizar o Bootstrap para acelerar a construção da interface, padronizar os elementos visuais e facilitar a adaptação para celulares. Nesta versão, os estilos foram feitos com CSS próprio.
